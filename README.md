# Персональная книга — Telegram Mini App и бот

Родитель открывает Mini App в Telegram, за 1–2 минуты отвечает на вопросы о ребёнке (в том числе выбирает тему книги и
пишет, что хочет в ней увидеть) и через 5–15 минут получает в чат PDF-фотокнигу: обложка с посвящением, 8 страниц, каждая —
одна широкая иллюстрация на весь разворот с короткими строками текста прямо на картинке, и финал с моралью и пожеланием.
Главный герой — сам ребёнок. Язык — русский или кыргызский, по желанию «исламский режим».

**Что уже работает:** вся цепочка «анкета → ожидание → просмотр → PDF → отправка в чат → отзыв» — без единого ключа
(на заглушках), а также с реальными сервисами: OpenAI, Gemini (бесплатно, для теста) и Cloudflare (бесплатно, для теста).
**Как продаётся:** бот закрыт, книги создают по личным ссылкам, которые владелец отправляет после оплаты (раздел
«Закрытый бот и личные ссылки» ниже). Цена PDF-книги по умолчанию 590 сом, мягкой печатной фотокниги — 1 290 сом (меняется в
админке). Лимит — 3 книги на человека в сутки. Оплата Telegram Stars сделана только как заготовка (`app/payments.py`) и
включится по отдельной команде.

## 1. Быстрый старт без ключей (5 минут)

### Шаг 1. Установите Python 3.11 или новее

* **Windows:** скачайте установщик на <https://www.python.org/downloads/>, запустите его и **обязательно поставьте галочку
  «Add python.exe to PATH»** внизу первого окна.
* **macOS:** скачайте установщик на том же сайте или выполните в Терминале `brew install python@3.12`.
* **Linux:** `sudo apt install python3 python3-venv` (или аналог для вашей системы).

### Шаг 2. Откройте папку проекта в терминале

* **macOS / Linux:** откройте «Терминал» и перейдите в папку с проектом: `cd путь/к/папке`.
* **Windows:** откройте папку в Проводнике, нажмите на адресную строку, напишите `cmd` и нажмите Enter.

### Шаг 3. Запустите одной командой

| Система | Команда |
|---|---|
| macOS, Linux | `./run.sh` (если пишет «permission denied» — один раз выполните `chmod +x run.sh`) |
| Windows | `run.bat` |

При первом запуске скрипт сам создаст виртуальное окружение, поставит зависимости (около минуты) и запустит сервер на
<http://localhost:8080>. Остановить — `Ctrl+C`.

Полезные команды (вместо `./run.sh` на Windows пишите `run.bat`):

| Команда | Что делает |
|---|---|
| `./run.sh dev` | запуск с `DEV_MODE=1`: Mini App открывается **в обычном браузере** по адресу <http://localhost:8080>. Только для теста у себя на компьютере |
| `./run.sh demo` | собирает пробную книгу из `samples/profile_example.json` без сервера → папка `demo_output/` (для кыргызского: `./run.sh demo samples/profile_ky.json`) |
| `./run.sh demo --from-env` | то же, но **текст и картинки делают сервисы из `.env`** (Gemini, Cloudflare, OpenAI) — самый быстрый способ увидеть настоящую книгу |
| `./run.sh check` | проверяет все ключи из `.env` и по-русски пишет, что исправить |
| `./run.sh story` | **показывает сказку**, которую пишет выбранный в `.env` текстовый провайдер (без картинок и сервера). Для кыргызского: `./run.sh story samples/profile_ky.json`, с описаниями для художника: `./run.sh story --full` |
| `./run.sh botprofile` | **оформляет бота в Telegram**: описание, «о боте», команды, кнопка меню (с `--name` — ещё и имя «Bala story bot»). Логотип нужно загрузить в @BotFather (`/setuserpic`): промты для генератора и временный логотип — в папке `branding/` |
| `./run.sh test` | запускает автоматические проверки |

> В обычном браузере без `dev` вы увидите страницу «Откройте приложение в Telegram» — так и должно быть: без подписи
> Telegram сервер никого не пускает.

## 2. Как открыть Mini App в Telegram (бесплатный туннель)

Telegram открывает Mini App только по публичному адресу **https**. Пока сервер работает у вас на компьютере, этот адрес даёт
бесплатный туннель Cloudflare.

1. Установите `cloudflared`:
   * macOS: `brew install cloudflared`
   * Windows: `winget install --id Cloudflare.cloudflared` (или скачайте с <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>)
   * Linux: <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>
2. В **первом** окне терминала запустите сервер: `./run.sh`.
3. Во **втором** окне запустите туннель: `cloudflared tunnel --url http://localhost:8080`.
   Среди строк найдите адрес вида `https://что-то-там.trycloudflare.com` — это ваш `WEBAPP_URL`.
4. Откройте файл `.env` в любом текстовом редакторе и впишите адрес в строку `WEBAPP_URL=` (без пробелов и без `/` в конце).
5. Остановите сервер (`Ctrl+C`) и запустите снова `./run.sh`. Бот при старте сам поставит кнопку меню «Создать сказку».
6. Откройте своего бота в Telegram, отправьте `/start` и нажмите кнопку **«Создать сказку»**.

**Важно:** при каждом запуске `cloudflared` адрес **новый**. Перезапустили туннель — впишите новый адрес в `.env` и
перезапустите сервер. Если Mini App открывается пустым или пишет об ошибке — проверьте `./run.sh check`: он покажет,
отвечает ли адрес из `WEBAPP_URL`.

Токен бота в `.env` уже стоит. Чтобы **копии книг и отзывы приходили вам**, отправьте боту команду `/id` — он ответит числом;
впишите его в строку `ADMIN_CHAT_ID=` и перезапустите сервер.

## 3. Где взять каждый ключ

Все значения записываются **только в файл `.env`** (он не попадает в git и не показывается в логах). После заполнения
запустите `./run.sh check` — он проверит каждый ключ и подскажет, что исправить.

| Строка в `.env` | Что это | Где взять | Цена |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота | в Telegram откройте **@BotFather** → `/mybots` → ваш бот → **API Token** (нового бота создаёт команда `/newbot`) | бесплатно |
| `WEBAPP_URL` | публичный https-адрес Mini App | в тесте — адрес из `cloudflared` (см. раздел 2), потом — адрес вашего сервера | бесплатно |
| `ADMIN_CHAT_ID` | ваш чат, куда приходят копии книг и отзывы (необязательно) | отправьте боту `/id` и впишите число из ответа | бесплатно |
| `OPENAI_API_KEY` | ключ OpenAI для текста и картинок | <https://platform.openai.com> → **API keys** → **Create new secret key**. Ключ показывается **один раз** — сразу скопируйте. Нужен баланс **от $5** (Settings → Billing). Для картинок может понадобиться подтверждение организации: Settings → Organization → General → **Verify Organization** | платно |
| `GEMINI_API_KEY` | бесплатный ключ Google для текста, **только для теста с вымышленными данными** | <https://aistudio.google.com> → **Get API key** | бесплатно |
| `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` | бесплатные картинки для теста | <https://dash.cloudflare.com> → **Workers AI** → **Use REST API** → **Create a Workers AI API Token** (токен покажут один раз). **Account ID** — на той же странице | бесплатно |

Названия моделей тоже в `.env` (`OPENAI_TEXT_MODEL`, `OPENAI_IMAGE_MODEL`, `GEMINI_MODEL`, `CLOUDFLARE_IMAGE_MODEL`) — в коде их нет.
Если модель переименуют, поменяйте строку и запустите `./run.sh check`.

**Вычитка кыргызского.** Для книг на кыргызском после редактора идёт ещё один проход: строгий «корректор-носитель языка»
исправляет орфографию, падежи, гармонию гласных, глаголы, кальки с русского и выдуманные слова, не трогая сюжет. Обычно
он работает на той же модели, что и основной текст. Если у вас есть более сильная модель, впишите её в необязательную строку
`TEXT_PROOF_MODEL=` — тогда только этот проход пойдёт на ней (пусто — основная модель). Если корректор ошибся или ответил
не по форме, остаётся текст редактора, заказ не падает. Проверка носителем языка всё равно нужна (раздел 5).

### Подключить Gemini для текста за 3 шага

1. На <https://aistudio.google.com> войдите своим Google-аккаунтом → **Get API key** → скопируйте ключ.
2. В `.env` впишите его в строку `GEMINI_API_KEY=` и поменяйте строку `TEXT_PROVIDER=mock` на `TEXT_PROVIDER=gemini`
   (`GEMINI_MODEL` уже заполнена).
3. Запустите `./run.sh check`, потом `./run.sh story` — через 10–60 секунд вы увидите настоящую сказку от Gemini.

Подписка Google AI Pro на API не влияет: ключ остаётся на бесплатном тарифе, поэтому только вымышленные данные.

### Какие сервисы включить

В `.env` две строки выбирают, кто пишет текст и кто рисует:

```
TEXT_PROVIDER=mock      # mock | openai | gemini
IMAGE_PROVIDER=mock     # mock | openai | cloudflare
```

| Набор | Для чего | Что вписать |
|---|---|---|
| `mock` + `mock` | проверка без ключей, заглушки | ничего |
| `gemini` + `cloudflare` | бесплатный тест **с вымышленными именами**, без фото | `GEMINI_API_KEY`, `CLOUDFLARE_*` |
| `openai` + `openai` | настоящие книги, герой похож на ребёнка (фото, референсы) | `OPENAI_API_KEY` |

После смены строк перезапустите сервер.

**Сколько это стоит и сколько влезает в бесплатный лимит** (по прайсам на 8 октября 2026, это оценка):

* **OpenAI:** текст `gpt-6-luna` — меньше цента за книгу (для кыргызского ещё один короткий запрос корректора). Картинок 9:
  обложка 1024×1024 и 8 широких страниц 2048×1024. Широкая страница в два раза больше по площади, поэтому стоит примерно в два раза
  дороже квадрата (оценка: цена картинки растёт с числом пикселей). Квадрат 1024×1024 стоил около $0,0055 (`low`), $0,0136 (`medium`),
  $0,052 (`high`); значит книга = 1 + 8·2 = 17 «квадратов»: при `low` около **$0,09**, при `medium` около **$0,23**, при `high` около
  **$0,88** (плюс до $0,03 за входные картинки-референсы). Раньше, при 9 квадратных картинках, было около $0,05 / $0,12 / $0,47.
  Это расчёт по площади, а не прайс: точную цену покажет первая настоящая книга в панели OpenAI. Время растёт примерно так же:
  широкая картинка рисуется дольше квадрата, на книгу уходит около 4–6 минут (параллелизм прежний: до 3 картинок и до 3 книг
  одновременно). Лимит новичка (уровень Build) — около 20 картинок в минуту; сервис сам ограничивает параллелизм.
* **Cloudflare:** бесплатно 10 000 «нейронов» в сутки. Одна картинка ≈ 58 «нейронов», книга (9 картинок) ≈ 520 → примерно **19 книг в сутки на
  весь сервис**. Потом ошибка до 00:00 по UTC (06:00 в Бишкеке) — поэтому книг на человека мало. FLUX schnell умеет только квадрат
  1024×1024, поэтому для страниц сервис обрезает квадрат по центру до 2:1 (получается 1024×512, растянутые до 2048×1024): для проверки
  вёрстки хватает, для продажи нужен OpenAI.
* **Gemini:** бесплатный тариф есть, но Google использует присланное для улучшения своих продуктов. Поэтому при
  `TEXT_PROVIDER=gemini` в Mini App появляется предупреждение «Тестовый режим: не вводите настоящие имена и не загружайте
  фото», а шаг с фото скрывается.

## 4. Как это устроено

Один сервис в одном процессе: веб-сервер (aiohttp) отдаёт Mini App и API, внутри работает бот (aiogram 3, long polling).
Если ваша платформа не держит долгоживущий процесс, бота нужно перевести на webhook — сейчас этого нет.

```
app/main.py          запуск: сервер + бот + уборка файлов
app/web.py           API и Mini App (проверка подписи Telegram на каждом запросе)
app/auth.py          проверка initData по инструкции Telegram
app/service.py       заказы, доступ по личным ссылкам, лимиты, очередь, отзывы, уборка (в том числе фото старше суток)
app/bookgen.py       текст → обложка (1024×1024) → 8 широких иллюстраций (2048×1024) → PDF (картинки сохраняются сразу)
app/layout.py        формат книги: размеры картинок, на какой половине разворота лежит текст
app/imaging.py       приведение картинки к размеру обрезкой по центру (cover-crop), фото ребёнка
app/overlay.py       текст поверх картинки: измерение фона, выбор оформления, подложки и свечение (Pillow), акценты
app/providers/       text_mock | text_openai | text_gemini, image_mock | image_openai | image_cloudflare
app/pdfbook.py       PDF-фотокнига разворотами 420×210 мм (reportlab, шрифты Nunito и Comfortaa из fonts/)
app/options.py       варианты ответов анкеты: темы, места, ценности, черты, языки (Mini App берёт их из /api/config)
app/bot.py           /start, кнопка web_app, /id, отправка книги в чат
app/payments.py      FreePayment (сейчас) и заготовка StarsPayment
webapp/              Mini App: index.html, style.css, app.js (без сборки)
tests/               автоматические проверки
```

**Формат книги (PDF).** Фотокнига, показанная разворотами: страница PDF — разворот 420×210 мм (два квадрата 210×210 мм
рядом), так книга печатается как фотокнига 21×21 см. Всего 10 разворотов:

| Разворот | Что на нём |
|---|---|
| 1. Обложка | слева бумажная страница «Для …» с посвящением; справа квадратная обложка 1024×1024 с названием, нарисованным прямо в картинке |
| 2–9. Страницы | **одна широкая иллюстрация 2:1 (2048×1024) на весь разворот, до самого края**, без бумажной страницы. Текст лежит прямо на картинке на спокойной половине: у нечётных страниц справа, у чётных слева |
| 10. Финал | две бумажные страницы: слева «Конец» и мораль в рамке, справа сердечко, пожелание и подпись «Эта книга создана специально для …» |

Картинки яркие, в стиле современного 3D-мультфильма. В промте для страницы (`app/prompts.py`, `build_page_prompt`) картинку просят нарисовать
как «широкий панорамный разворот 2:1»: главные герои крупно, в движении (не за партой) на одной половине, а другая половина — спокойное
мягкое небо или фон, ничего важного, место под текст. Какая половина спокойная, зависит от номера страницы: справа у нечётных, слева у чётных.
Во все промты картинок добавлено правило: не рисовать существующих персонажей под товарными знаками или авторским правом, а при упоминании
известного типажа рисовать собственный похожий образ.

Текст на странице: крупный (**30–18 pt**, подбирается так, чтобы влезло), Nunito ExtraBold, по центру блока шириной около 150 мм
(несколько коротких строк), тёмно-коричневый `#3A2E25`. Красно-коралловым `#D4472F` выделены только прямая речь после тире и короткие возгласы (до 4 слов с «!»); длинные предложения с «!»
не красятся, а акцентных слов не больше 60% страницы (`app/overlay.py`). Внизу своей половины маленький золотой кружок с номером страницы. Шрифты — Nunito и Comfortaa
(лицензия OFL, лежат в `fonts/`, поддерживают кириллицу и буквы ү ө ң); DejaVu Serif остался запасным. Текст в PDF векторный и выделяется мышью.

### Как текст лежит на картинке: `TEXT_OVERLAY_MODE`

Чтобы текст читался на любой картинке, сервис перед вёрсткой каждой страницы измеряет участок картинки под текстом (средняя яркость, мелкие детали
и края, смесь светлого и тёмного) и подбирает оформление (`app/overlay.py`, пороги — константы в начале файла):

| Что под текстом | Оформление |
|---|---|
| спокойный светлый фон | `plain-light`: тёмный текст с очень мягким светлым свечением за буквами, без подложки |
| тёмный, средний по яркости или пёстрый фон | `fade`: картинка плавно «тает» в кремово-белый `#FFFDF6` к внешнему краю книги (горизонтальный градиент, у сгиба прозрачный, у края около 92%), текст тёмный сверху |

Переключатель в `.env` (необязательный, по умолчанию `auto`): `TEXT_OVERLAY_MODE=auto | fade | plate | plain`.

* `auto` — выбор по таблице выше (так задумано по умолчанию).
* `fade` — всегда плавное таяние в белый.
* `plate` — всегда мягкая скруглённая подложка с размытым краем (кремовая на светлом фоне, тёмная полупрозрачная с кремовым текстом на тёмном).
* `plain` — ничего не накладывать на картинку: на светлом фоне тёмный текст со светлым свечением, на тёмном кремовый текст с тёмной тенью
  (на пёстром фоне свечение сильнее).

Градиент, подложка и свечение — PNG с прозрачностью, заранее нарисованные Pillow; текст остаётся векторным. На тёмном фоне акцентный цвет
ярче (`#FF7A63`). Оформление каждой страницы записывается в `layout.meta.json` рядом с книгой и отдаётся Mini App как `pages[].text_style`.

### Анкета: тема, пожелание, любимые герои

Кроме имени, возраста, внешности, увлечений, черт, места и ценности в анкете есть поля, которые делают книгу не только сказкой:

| Поле | Что это | Правила |
|---|---|---|
| `topic` | тема книги, один вариант из `options.TOPICS`: `adventure` (Приключение, по умолчанию), `dinosaurs`, `space`, `animals`, `superheroes`, `pirates`, `sea`, `friends`, `kindness`, `life_lesson` (Учимся жизни: зубки, сон, садик, врач), `custom` (Своя тема) | неизвестный id — ошибка; если поле не прислано, берётся `adventure` |
| `topic_custom` | своя тема словами (для `topic = custom`) | до 120 символов; у `custom` нужно либо оно, либо `request` |
| `request` | «Что вы хотите увидеть в книге?» | необязательно, до 300 символов |
| `favorites` | «Любимые герои, животные, игрушки» | необязательно, до 120 символов |
| `world` | мир книги («как в любимом мультфильме», но без чужих героев): `forest_house`, `rescue_team`, `workshop_helpers`, `ninja_animals`, `caped_hero`, `kingdom`, `dino_friend`, `space_crew`, `builders`, `mountain_friends`, `custom` (`options.WORLDS`) | необязательно; неизвестный id — ошибка `world`; миры-команды (ниндзя, спасатели, мастерята, космос, горные друзья, королевство, стройка) дают помощника-команду из 3–4 друзей |
| `cartoons` | любимые мультфильмы или герои | необязательно, до 120 символов; только вдохновение (роль и настроение, не имена и внешность), стирается через `KEEP_FILES_DAYS` |
| `style` | стиль картинок: `cartoon3d` (3D-мультик, по умолчанию), `flat2d` (2D-мультик), `realistic` (реалистичный, лицо как на фото) (`options.STYLES`) | необязательно; неизвестный или пустой — `cartoon3d`, ошибки нет |

Все три текстовых поля чистятся как остальные (управляющие символы и `<` `>` убираются) и попадают писателю внутри `<child>` как
`topic_label`, `request`, `favorites` (`app/profile.py`, `Profile.for_model`). После `KEEP_FILES_DAYS` дней из базы стираются `request`,
`favorites` и `topic_custom` (как посвящение); сама тема остаётся для статистики. Описание для Mini App: `.impeccable/backend-contract-v2.md` и `.impeccable/backend-contract-v3.md` (миры, стили, акценты).

**Как пишется книга сейчас** (подробно в `.impeccable/writer-notes.md`): сюжет простой и пересказывается за 5 секунд одной фразой (один из 8 каркасов, `logline`, `meaning`), три шага в трёх НОВЫХ местах, тон радостный (восклицания, звуки, счёт, яркие слова), страницы до 18 / 28 / 36 слов по возрасту. Помощник может быть командой (мир-команда или просьба «четыре черепашки-ниндзя»): каждый друг в `cast`, в тексте и на картинках. После автора идёт проверка «понятно ли пятилетнему» (с переписыванием, до двух раз), потом редактор. Код ловит технические слова, соседние кадры в одном месте, чужие бренды, повторы одного слова.

**API** (везде, кроме `/api/health`, заголовок `Authorization: tma <initData>`):

| Запрос | Что делает |
|---|---|
| `GET /api/config` | активные провайдеры, лимиты, принимается ли фото, цена, предупреждение о приватности, варианты ответов (в том числе `options.topics`), `book_format` (размеры картинок, число страниц), `access` (есть ли доступ и сколько книг осталось), `print` (предложение печатной версии) |
| `POST /api/orders` | анкета (JSON; с фото — multipart: поле `profile` и файл `photo`) → `order_id`. Проверяет подпись, лимит, согласие на фото |
| `GET /api/orders/{id}` | статус `queued`/`writing`/`drawing`/`assembling`/`done`/`error`, прогресс, страницы `{text, lines, image_url или null, text_side, text_style}`, `pdf_url` |
| `GET /api/orders/{id}/img/{cover\|p1..p8}.jpg`, `GET /api/orders/{id}/book.pdf` | файлы — только владельцу заказа |
| `POST /api/orders/{id}/send` | повторная отправка PDF в чат (добавлено сверх задания: если пользователь ещё не запускал бота) |
| `POST /api/feedback` | `{order_id, rating: "up"\|"down", comment, would_pay: yes\|maybe\|no}` |
| `POST /api/admin/invites`, `GET /api/admin/invites`, `POST /api/admin/invites/{token}/revoke` | только владелец: создать, посмотреть и отозвать личные ссылки |
| `POST /api/admin/settings` | только владелец: цена, WhatsApp, цена печати, закрытый режим, оплата по QR |
| `GET /api/health` | проверка, что сервер жив |

Картинки в `<img>` и скачивание PDF не умеют отправлять заголовок, поэтому владелец получает в ответе `GET /api/orders/{id}`
подписанные ссылки `?t=…` (привязаны к заказу и владельцу, живут несколько часов). Файлы чужого заказа не отдаются никогда.

### Приватность и безопасность

* Ключи только в `.env`; в `.gitignore` стоят `.env` и `data/`; в `.env.example` секретные строки пустые; в логи и тексты ошибок
  ключи не попадают (автоматическая замена на `***`; библиотека `httpx` не пишет адреса запросов).
* Подпись `initData` проверяется на каждом запросе, данные старше 24 часов отклоняются. `DEV_MODE=1` отключает проверку —
  при включении в лог печатается заметное предупреждение. **Для людей всегда `DEV_MODE=0`.**
* Анкета ребёнка передаётся модели внутри `<child></child>` как данные; из текста вычищаются управляющие символы и угловые
  скобки; ответ модели проверяется по схеме (ровно 8 страниц, все поля непустые), при ошибке — до 2 повторов с текстом ошибки.
* Фото: нужна галочка согласия родителя; при загрузке удаляются метаданные (EXIF, геометки); фото уходит **только**
  провайдеру с референсами (OpenAI), не отправляется Gemini и Cloudflare. **Обещание людям: фото удаляется
  автоматически после создания книги и в любом случае не позже чем через 24 часа после загрузки.** Сразу после
  генерации (удачной или с ошибкой) файл стирается; если заказ ждёт оплаты или очереди, фото убирает ежечасная уборка
  по времени файла (`purge_old_photos` в `app/service.py`, граница 23 часа, чтобы даже с паузой между уборками не
  выйти за сутки).
* Через `KEEP_FILES_DAYS` дней (по умолчанию 7) удаляются файлы книги, а из базы стираются имя, внешность и посвящение.
* Имя ребёнка в промты для картинок не попадает; в логи имена и фото не пишутся.
* Лимиты: `MAX_BOOKS_PER_USER_PER_DAY` книг на человека в сутки (неудачные попытки не считаются), не больше одной книги
  одновременно на человека и 3 одновременных генераций на весь сервис.

## 5. Что обязательно проверить человеку до публичного запуска

* **Кыргызский текст** пишет нейросеть, потом его автоматически вычитывает второй проход «корректор» (раздел 3), но
  носитель языка всё равно обязательно должен прочитать его до продажи. Кыргызские тексты заглушки
  (`app/providers/text_mock.py`) — только пример для проверки шрифтов.
* **Исламский режим**: правила в `app/prompts.py` (блок `ISLAMIC_BLOCK`) должен проверить знающий человек. Цитаты аятов и
  хадисов запрещены полностью: «проверенного списка» цитат пока нет.
* Склонение имён в подписях «Книга для Айдара» сделано простым правилом (`app/declension.py`); редкие имена оно может склонить
  неточно — тогда имя остаётся без изменений.
* Оплата в Кыргызстане картой или кошельком (GoPay, FreedomPay, MBank, O!Money) в Mini App не подключена: это отдельное
  решение, которое нужно согласовать с юристом.

### Оплата Telegram Stars (заготовка, не включена)

Цифровые товары в ботах и Mini Apps по правилам Telegram продаются только за Stars. Порядок работы описан в начале
`app/payments.py`. По условиям для разработчиков Telegram за каждую Star выплачивается эквивалент **0,013 USD**; 590 сом ≈ $6,75 ≈
**520 Stars** — перед включением цену нужно пересчитать по актуальному курсу.

## 6. Сверка с документацией (где задание и документация расходились)

Параметры взяты из официальных документаций (проверено 8 октября 2026). Расхождения с текстом задания:

* **OpenAI, ошибки денег:** нехватка средств и лимиты расходов приходят как 429 с кодами `credit_balance_exhausted`,
  `organization_spend_limit_exceeded`, `project_spend_limit_exceeded`, `organization_usage_limit_exceeded` (тип может оставаться
  `insufficient_quota`) — обрабатываются все.
* **OpenAI, текст:** модели GPT-6 «думающие»: `temperature` для них недоступна, а вместо `max_tokens` существует
  `max_completion_tokens`. Поэтому ни тот, ни другой параметр не передаются.
* **OpenAI, подтверждение организации:** в документации сказано «может понадобиться», жёсткого требования нет — скрипт
  `check_keys.py` лишь напоминает об этом.
* **OpenAI, `input_fidelity`:** для моделей 2.5 в документации не описан — не передаётся. Число токенов картинки в документации
  названо оценкой.
* **Gemini:** «мысли» модели входят в `maxOutputTokens`, поэтому лимит поставлен 16 384, а не 8 192. Модель `gemini-3.1-flash-lite`
  по документации будет отключена 7 мая 2027 года (замена — `gemini-3.5-flash-lite`).
* **OpenAI, размеры:** `images/generations` и `images/edits` принимают любой размер `ШxВ`, где обе стороны кратны 16 и отношение
  не больше 3:1: страница просится `2048x1024` (2:1), обложка `1024x1024`.
* **Cloudflare:** FLUX принимает только `prompt` и `steps`; ни `width`/`height`, ни `seed` схемой не предусмотрены, поэтому не
  передаются (картинки всегда квадратные, сервис обрезает их по центру до нужного соотношения). При исчерпании дневного лимита приходит ошибка 3036 (HTTP 429) — повторы в этом случае отключены.
* **Telegram:** для `Telegram.WebApp.downloadFile` сервер должен присылать `Content-Disposition: attachment` и
  `Access-Control-Allow-Origin: https://web.telegram.org` — так и сделано. Срок годности `initData` (24 часа) — наше правило,
  Telegram максимальный возраст не задаёт. Поле `signature` входит в строку проверки (исключается только `hash`).

## Закрытый бот и личные ссылки

По умолчанию бот **закрыт**: книги создают только люди, открывшие вашу личную ссылку, и вы сами (владелец, `ADMIN_CHAT_ID`).
Всем остальным бот отвечает: «Бот работает по личным ссылкам. Ссылку на доступ вы получите после оплаты: напишите нам в
WhatsApp.» (с вашим номером ссылкой, если он вписан в настройки), а Mini App показывает то же самое.

**Как продавать, по шагам**

1. Человек пишет вам в WhatsApp и платит любым удобным способом (перевод, наличные).
2. Вы открываете админку (в боте команда `/admin` → «Открыть админку») и создаёте личную ссылку: выбираете, сколько книг она
   даёт (обычно 1), и пишете заметку, кому она (например, «Мама Айдара»).
3. Копируете получившуюся ссылку вида `https://t.me/<имя бота>?start=inv_…` и отправляете человеку в WhatsApp.
4. Человек нажимает на ссылку, бот пишет «Доступ открыт: у вас 1 книга» и показывает кнопку «Создать сказку». Вам в чат
   приходит сообщение, что ссылку открыли (с вашей заметкой).

**Правила**

* Ссылка работает **один раз**: первый, кто её открыл, получает книги на свой счёт, остальным бот отвечает, что ссылка
  уже использована. Неиспользованную ссылку можно отозвать в админке (использованную — нельзя). В списке админки видны
  последние 30 ссылок: кому дана, открыта ли.
* Каждая созданная книга тратит одну книгу со счёта. Если создание закончилось ошибкой (не по вине человека), книга
  возвращается на счёт автоматически, можно попробовать ещё раз. Если человек сам отменил заказ, книга не возвращается.
* Суточный лимит (`MAX_BOOKS_PER_USER_PER_DAY`, по умолчанию 3) действует и для тех, у кого есть книги.
* Вам (владельцу) ссылки не нужны: книги создаются без ограничений и ничего не списывают. Если вы сами откроете чужую
  ссылку, она не сгорит: бот скажет, что ссылка не использована, и её можно отправлять клиенту.
* Чтобы открыть бот для всех, выключите «Закрытый бот» в настройках админки (счёт книг при этом не тратится). Чтобы закрыть
  снова, включите.
* Не включайте одновременно закрытый бот и приём оплаты по QR (раздел ниже): книга будет списываться ещё до оплаты в приложении.

**Цены и печатная версия.** В настройках админки: цена PDF-книги (по умолчанию «590 сом»), цена мягкой печатной фотокниги
21×21 см (по умолчанию «1 290 сом») и **номер WhatsApp** (цифры с кодом страны, например `996555123456`, допустимо вписать
`+996 555 123-456`). Пока номер пустой, предложение печати выключено. Когда номер задан, Mini App показывает блок «Хотите
заказать печатную версию?» с кнопкой в WhatsApp, а после доставки PDF бот присылает вторым сообщением цены и кнопку
«Заказать в WhatsApp».

**Фото ребёнка.** Обещание людям: фото удаляется автоматически после создания книги и в любом случае не позже чем
через 24 часа после загрузки. Это проверяют автотесты (`tests/test_access.py`).

Все данные (ссылки, счёт книг, настройки) лежат в базе `skazka.sqlite3` в папке данных: на Railway подключите Volume `/data`,
иначе при обновлении выданные ссылки и оставшиеся книги пропадут. Описание API для Mini App: `.impeccable/backend-contract.md`.

## Оплата переводом по QR-коду и админка

Это ручная схема без платёжной системы: деньги идут напрямую владельцу, он сам проверяет поступление.

1. Впишите в `.env` (и в Variables на Railway) `ADMIN_CHAT_ID`: отправьте боту `/id`, он ответит числом.
2. Откройте бота и отправьте `/admin` (или нажмите «Админка» на стартовом экране Mini App).
3. Вкладка «Настройки»: загрузите свой QR-код (банк или кошелёк), поставьте цену, при желании измените подсказку для покупателя, включите переключатель «Приём оплаты по QR» и нажмите «Сохранить».
4. Теперь после анкеты покупатель видит QR, платит у себя в банковском приложении и нажимает «Отправить чек». Вам в чат приходит фото чека с кнопками «Подтвердить» / «Отклонить» (то же самое есть во вкладке «Чеки» админки).
5. Только после «Подтвердить» сказка начинает создаваться. После «Отклонить» покупатель видит причину и может прислать новый чек. Заказ без чека можно подтвердить вручную («Подтвердить без чека»).

Важно: настройки, QR и чеки лежат в папке данных (`DATA_DIR`). На Railway к сервису нужно подключить Volume с путём `/data`, иначе всё сотрётся при следующем обновлении. Неоплаченные заказы без чека удаляются сами через 3 дня.
